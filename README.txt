कक्षा 8 जलवायु-मौसम क्विज
==========================
यह GitHub Pages के लिए तैयार static quiz है।

मुख्य विषय:
- जलवायु और मौसम
- जलचक्र / महासागरीय चक्र
- वाष्पीकरण, संघनन, वर्षण
- नदी, उद्गम, मुहाना, अपवाह
- अपरदन, निक्षेपण, अपक्षय
- हिमनद
- समुद्री जल, ज्वार-भाटा, महासागरीय धाराएँ
- जलवायु को प्रभावित करने वाले कारक
- ऐतिहासिक, सांस्कृतिक और भौगोलिक स्रोत
- स्रोतों की तुलना और विश्वसनीयता
- जल संरक्षण और वर्षा जल संचयन

GitHub पर:
1. ZIP को extract करें।
2. सभी 3 फाइलें एक ही folder में रखें।
3. GitHub repository में index.html, style.css और script.js upload करें।
4. Settings > Pages में Deploy from branch चुनें।
5. Branch में main और folder में /root चुनकर Save करें।
