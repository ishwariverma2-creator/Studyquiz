UTET HARD QUESTION WEB SERIES – MATHEMATICS

GitHub Pages के लिए:
1. इस ZIP को extract करें।
2. GitHub में नया repository बनाएँ।
3. index.html को repository की root में upload करें।
4. Settings → Pages → Deploy from branch → main / root चुनें।
5. Save करें और कुछ समय बाद generated Pages link खोलें।
